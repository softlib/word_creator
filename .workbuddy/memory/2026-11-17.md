# 2026-11-17

- 在 `DocxTool/` 中实现了基于工作空间 OfficeXML4D 库的通用 docx 生成工具：
  - `uDocxTemplate.pas`：JSON 配置驱动的文档构建单元，支持标题/段落/富文本/超链接/列表/表格/分页/图片（路径或 Base64，自动识别 PNG/JPEG/GIF/BMP 尺寸并等比缩放），依赖 System.JSON/System.Zip 等系统单元。
  - `DocxGen.dpr`：命令行入口（`-c` 配置、`-o` 输出），`DocxGen.dproj` + `build.bat` 可用 msbuild 构建，`run_sample.bat` 一键生成示例。
  - 示例 `config.sample.json`、`images/logo.png`、`images/chart.png`，输出 `output/sample.docx`。
- 验证：本机 Delphi（Studio 23.0 目录，编译器 36.0）编译通过；生成的 docx 内 2 张图片正确写入 `word/media/image1.png`、`image2.png`，document.xml/rels/header/footer/numbering 均为合法 XML，中文内容无乱码。
- 注意事项：Delphi 源码需保存为 UTF-8 with BOM（编译器不接受 `{$codepage UTF8}` 指令）；本机 `reg.exe` 被安全策略拦截，因此构建时需显式设置 `BDS` 环境变量。OfficeXML4D 的 writer 会把所有表格排在全部段落之后，配置中应将表格块置于末尾；该库 writer 也不输出 docProps/core.xml。
